🔍 Host Discovery Techniques

Before scanning ports, identify which hosts are alive on the network. Choose the right technique based on your target environment.

📡

Ping Sweep (-sn)

Fastest way to find live hosts. Sends ICMP echo requests and TCP ACK probes to determine if a host is online without port scanning.

nmap -sn 192.168.1.0/24
🚫

Skip Discovery (-Pn)

Treat all targets as online. Use when ICMP is blocked by firewalls or when you know targets are up but don't respond to pings.

nmap -Pn target.com
🔌

TCP SYN Ping (-PS)

Sends empty TCP SYN packets to specified ports. If SYN-ACK or RST received, host is up. Bypasses ICMP-blocking firewalls.

nmap -PS22,80,443 target.com
📤

TCP ACK Ping (-PA)

Sends TCP ACK packets. Useful for bypassing stateless firewalls that block SYN but allow established connections.

nmap -PA80,443 target.com
📨

UDP Ping (-PU)

Sends UDP packets to specified ports. ICMP port unreachable indicates closed port; no response may mean open or filtered.

nmap -PU53,161 target.com
🏠

ARP Ping (-PR)

Fastest method for local Ethernet networks. Requires root privileges. Nmap uses ARP automatically for local targets.

sudo nmap -PR 192.168.1.0/24

🔌 Port Scanning Techniques

Different scan types trade off between speed, stealth, and accuracy. Select based on your target's defenses and your privileges.

⚡

TCP SYN Scan (-sS)

The default and most popular scan. Sends SYN, receives SYN-ACK, then sends RST instead of completing handshake. Fast and stealthy.

sudo nmap -sS target.com
🔗

TCP Connect Scan (-sT)

Completes full 3-way handshake via OS connect() system call. Use when you lack root privileges. Easily logged by target.

nmap -sT target.com
📻

UDP Scan (-sU)

Checks UDP services like DNS, SNMP, DHCP. Very slow because many ports return ICMP unreachable. Often combined with TCP scans.

sudo nmap -sU -p 53,161,500 target.com
🧱

TCP ACK Scan (-sA)

Never determines open ports. Instead, maps firewall rulesets by distinguishing stateful (drop) vs stateless (reject) filters.

sudo nmap -sA target.com
👻

Null / FIN / Xmas Scans

Exploit RFC 793 loopholes. Null (-sN) sends no flags; FIN (-sF) sends FIN; Xmas (-sX) sends FIN+PSH+URG. Stealthy but unreliable on Windows.

sudo nmap -sF target.com
🎭

Idle Scan (-sI)

Ultimate stealth scan. Bounces scan off a "zombie" host. Your IP never appears in target logs. Requires finding suitable zombie.

sudo nmap -sI zombie_host target.com

📜 Nmap Scripting Engine (NSE)

NSE transforms Nmap from a port scanner into a vulnerability assessment tool. Scripts are categorized by safety and purpose.

🛡️

Safe Scripts

Cannot crash services or exploit vulnerabilities. Good for routine scanning and service enumeration without risk.

nmap --script safe target.com
⚠️

Intrusive Scripts

May crash services or trigger IDS alerts. Use with caution on production systems. Includes brute-force and exploitation attempts.

nmap --script intrusive target.com
🐛

Vulnerability Scripts

Check for known CVEs and common misconfigurations. Essential for security assessments. May trigger security tools.

nmap --script vuln target.com
💥

Exploit Scripts

Actually attempt to exploit vulnerabilities. High risk of crashing services. Only use on systems you own or have explicit permission to test.

nmap --script exploit target.com
🔐

Auth Scripts

Test authentication mechanisms. Check for default credentials, weak passwords, and authentication bypasses.

nmap --script auth target.com
🔍

Discovery Scripts

Enumerate network resources, users, shares, and services. Great for internal reconnaissance and mapping.

nmap --script discovery target.com

🥷 Firewall & IDS Evasion

When scanning hardened targets, these techniques help avoid detection by firewalls, IDS, and logging systems.

🧩

Packet Fragmentation (-f)

Splits probe packets into tiny 8-byte fragments. Many simple packet filters and IDS can't reassemble fragments, allowing probes through.

sudo nmap -f target.com
🎭

Decoy Scanning (-D)

Hide your real IP among decoy hosts. Target logs show scans from multiple IPs, making it hard to identify the real scanner.

sudo nmap -D RND:5,ME target.com
🎪

Source IP Spoofing (-S)

Spoof your source IP address. Useful when you control a network that the target routes back to you (rarely practical on internet).

sudo nmap -S 192.168.1.100 target.com
🔢

Source Port (-g)

Use a trusted source port like 53 (DNS) or 20 (FTP data). Some firewalls allow all traffic from these "trusted" ports.

sudo nmap -g 53 target.com
📏

Random Data Length

Add random padding to packets to change their size. Helps evade signature-based detection that looks for specific packet sizes.

sudo nmap --data-length 50 target.com
🔀

Randomize & Spoof

Shuffle scan order and randomize MAC address to avoid pattern detection and MAC-based filtering on local networks.

sudo nmap --randomize-hosts --spoof-mac 0 target.com
