# Nmam - Network Scanner Dashboard

A modern, interactive web dashboard for configuring, generating, and simulating Nmap network scans. Built with pure HTML, CSS, and JavaScript – no external dependencies except for fonts.

![Nmap Pro Dashboard Screenshot](screenshot.png)

## 🚀 Features

- **Intuitive Scan Builder** – Configure every aspect of an Nmap scan:
  - Target specification (IP, CIDR, ranges, hostnames)
  - Host discovery methods (ping sweep, TCP SYN/ACK, UDP, ARP)
  - Port scanning techniques (SYN, Connect, UDP, ACK, Null, FIN, Xmas, Idle)
  - Port specification (top 100, fast mode, all ports, custom ranges)
  - Service & version detection (with OS fingerprinting)
  - NSE script categories (default, safe, intrusive, vuln, exploit, etc.)
  - Timing templates (Paranoid to Insane)
  - Firewall/IDS evasion options (fragmentation, decoys, spoofing, etc.)
  - Output format selection

- **Real-time Command Preview** – See the exact Nmap command generated by your options, with metadata (requires root, estimated time, stealth level).

- **Simulated Scan Execution** – Run a mock scan with a live progress bar, status updates, and a scrolling log that mimics real Nmap output.

- **Results Dashboard** – View scan summaries (hosts up, open ports, services, vulnerabilities) and detailed host information, including open and filtered ports with service versions.

- **Host Detail Modal** – Dive into per‑host data: open ports, filtered ports, OS fingerprinting.

- **Scan History** – Keep track of past scans with timestamps, targets, and execution times.

- **Educational Info Panels** – Learn about host discovery, port scanning techniques, NSE scripts, and evasion tactics directly in the app.

## 🛠️ Technologies

- **HTML5** – Structure of the dashboard.
- **CSS3** – Modern dark theme with smooth animations, flexbox/grid layouts, and custom properties.
- **Vanilla JavaScript** – All logic, state management, and DOM manipulation are done without any frameworks.
- **Google Fonts** – Inter (sans‑serif) and Fira Code (monospace) for a polished look.

## 📦 Getting Started

1. Clone this repository or download the `index.html` file.
2. Open the `index.html` file in any modern web browser.
3. No server or installation required – everything runs client‑side.

## 🧭 Usage

1. **Configure your scan** using the cards on the “New Scan” tab.
2. **Review the generated command** at the bottom of the page.
3. Click **“Run Scan”** to start a simulated scan.
4. Watch the progress modal, then view results in the **“Results”** tab.
5. Click on any host’s **“Details”** button for a deeper look.
6. Explore the **“Host Discovery”**, **“Port Scanning”**, **“NSE Scripts”**, and **“Evasion”** tabs for explanations and examples.

> **Note:** This is a simulation – no actual network scanning is performed. The generated commands are for demonstration and learning purposes only.
